# Сайт Космопорта

По прямому указанию пользователя от 31 октября 2026 года сайт создаётся на основе ранее размещённой «Космосферы». Исходная композиция, стили, иллюстрации и локальные шрифты взяты из `ivankirillov414-art/profisport-site/cms/sites/kosmosfera`. Лицензии локальных шрифтов сохранены в `public/site/assets/`.

Новое название — «Космопорт». Пользователь подтвердил даты: с 24 ноября 2026 года по 18 января 2027 года. Из источника билетного приложения подтверждены Оренбург, ТРЦ «Мармелад», Шарлыкское шоссе, 1/2, а также правило детского пригласительного при покупке взрослого билета. Неуточнённые цена, часы работы и контакты остаются пустыми в настройках. Старая цена 849 ₽ не выдаётся за подтверждённую цену новой редакции сайта.

Публичный сайт отдаёт только опубликованную версию. Сотрудник с правами редактора сохраняет черновик и отдельно публикует его; устаревшее сохранение отклоняется с HTTP 409. Текст и атрибуты экранируются, HTML из редактора не исполняется. Изображения выбираются из локального каталога сайта. Публикация и сохранение записываются в аудит.

Сайт показывает страницы и план посещения; продажа открывается только после заполнения реальной цены и HTTPS-адреса покупки. Скачанный план группы и событие календаря не создают заявку или бронь. Учёт использованных пригласительных доступен сотрудникам в CRM; посетитель не может самостоятельно отметить проход через публичный сайт.
