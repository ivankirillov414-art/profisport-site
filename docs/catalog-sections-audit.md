## Что исправлено

- Все направления классификатора связаны с разделом главной страницы. Для неизвестных будущих типов предусмотрен видимый раздел «Другие товары».
- SUP-борды и аксессуары к ним доступны через «Туризм и водный спорт» и отдельные подразделы «SUP-борды» / «SUP-аксессуары». Учтены написания SUP, сапборды, сап-борд и сабборды.
- Подразделы доступны целиком через выпадающий список, без отсечения после первых десяти.
- Фильтры, переходы из меню и карточек используют одну схему разделов.
- Обновлён ключ кеша нормализованного каталога, чтобы старая классификация не сохранялась в браузере.
- Проверены отрицательные случаи: тормозные колодки / лодки, ролики для пресса / роликовые коньки, металлический бокс / бокс, скандинавская расцветка / ходьба, штанга велокресла / спортивная штанга.
